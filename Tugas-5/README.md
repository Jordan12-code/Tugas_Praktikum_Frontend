Website toko poster dan wallpaper anime (Mugen Art) menggunakan Next.js dan React Bootstrap.

- Carousel ada di bagian Beranda
- Menu navbar yang aktif berubah warna sesuai section yang sedang dilihat
- Tampilan responsif untuk HP, tablet, dan laptop

Cara menjalankan:

```
npm install
npm run dev
```

Lalu buka http://localhost:3000
